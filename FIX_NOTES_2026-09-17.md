# PArAsYtE Browser v0.3 - audit/fix notes

- Replaced the desktop iframe browsing path with native Electron `WebContentsView` tabs.
- Sites such as YouTube now load as top-level Chromium content in the desktop application.
- Implemented real independent tabs, close/switch/new-tab shortcuts and reopen-last-closed tab.
- Routed `target=_blank` / window-open requests into PArAsYtE tabs.
- Added a real bookmarks library and native desktop download activity.
- Removed the non-functional Extensions control until an extension engine exists.
- Removed duplicate in-app macOS traffic lights; the native title bar is the only window-control surface.
- Preserved private/local-host blocking and added guest-session request-layer blocking for literal private hosts.
- Guest browser permissions are denied by default; guest content runs sandboxed with Node disabled.
- Added safer external protocol handling and renderer-crash state reporting.
- Removed dead SSO UX and replaced the fake Remember-me checkbox with accurate secure-session status.
- Updated Settings privacy/about text and desktop architecture documentation.
- Added mobile iOS/Android architecture and a Brave-informed browser roadmap.

Verification in the audit environment:

- Policy tests: 13/13 pass.
- `node --check desktop/main.cjs`: pass.
- `node --check desktop/preload.cjs`: pass.
- TypeScript parse check: no syntax diagnostics; the container is missing the project's installed type packages, so a full build must be rerun on the development Mac.

Release blocker: the received desktop lockfile uses Electron 33, which is outside Electron's supported release window. Upgrade Electron before distributing installers.
